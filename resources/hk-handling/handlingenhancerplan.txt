ARCHITECTURE:
─────────────
  hk-vehlib          = LIBRARY (shared utility layer)
                        Exports functions that ANY script can call.
                        Does NOT run features itself — it provides the TOOLS.
                        e.g. vehlib.setTorque(veh, mult)
                             vehlib.getWheelSpin(veh, wheel)
                             vehlib.applyLift(veh, force, offset)
                             vehlib.capHandling(veh, field, mult)
                             vehlib.restoreHandling(veh)
                             vehlib.detectState(veh) → {rpm, gear, speed, ...}

  hk-racecam         = CAMERA + VISUAL SUSPENSION (uses hk-vehlib)
                        Chase cam, airborne cam, drag cam
                        + launch squat, brake dive, air suspension visuals

  hk-vehdynamic      = HANDLING FEATURES (uses hk-vehlib)
                        Launch control, TC, ABS, drift mode, wheelie,
                        downforce, ESC, DRS — the "Dynamic" product.

  This is the same pattern LegacyDMA uses:
    - Core library (shared natives wrapper + state tracking)
    - CHASER (their camera product, uses the library)
    - Dynamic (their handling product, uses the library)
