# hk-debugtracker

Server performance and telemetry tracker with anti-cheat checks, flood alerts to Discord and screenshot upload to Zipline.

## Setup
Optional: set `Config.FloodWebhook` in `config.lua` to a Discord webhook for flood alerts, add your staff identifiers to `Exempt`, and set the `hk_zipline_token` convar plus `Config.Screenshot.UploadHost` if you use Zipline screenshots.
