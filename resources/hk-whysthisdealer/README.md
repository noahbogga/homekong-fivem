# hk-whysthisdealer

"Why's This Dealer?" meme: your car bounces on its suspension in time with the song, synced for nearby players.

## Audio (not included)
The song isn't shipped because it's copyrighted. Add your own version:
1. Put your audio file at `html/whysthisdealer.mp3` (same name, or change the name in `fxmanifest.lua` and `html/app.js`).
2. Set `Config.ClipSeconds` in `config.lua` to its length in seconds, so playback stops on time.
3. Set `Config.BPM` in `config.lua` to your track's tempo so the bounces stay on the beat.
